# 애그리거트의 영속성 전파 (★★)

#ddd #repository #jpa-mapping #cascade #concept

## Overview Table (한눈에 비교)

| 매핑 타입 | `cascade` 설정 필요? | 이유 |
|-----------|----------------------|------|
| **`@Embeddable`** | ❌ **불필요** | 함께 저장되고 삭제된다 |
| **`@Entity`** (`@OneToOne`, `@OneToMany`) | ⭕ **필요** | `cascade` 기본값이 없다 |

## 원칙

> [!important]
> 애그리거트가 완전한 상태여야 한다는 것은 **애그리거트 루트를 조회할 때뿐만 아니라 저장하고 삭제할 때도 하나로 처리해야 함**을 의미한다.
>
> - **저장 메서드**는 애그리거트 루트만 저장하면 안 되고 **애그리거트에 속한 모든 객체를 저장**해야 한다.
> - **삭제 메서드**는 애그리거트 루트뿐만 아니라 **애그리거트에 속한 모든 객체를 삭제**해야 한다.

```
   repository.save(root)
        ▼
   루트 + 속한 모든 객체가 함께 저장되어야 한다

   repository.delete(root)
        ▼
   루트 + 속한 모든 객체가 함께 삭제되어야 한다
```

## `@Embeddable` — 설정 불필요

> [!tip]
> **`@Embeddable` 매핑 타입은 함께 저장되고 삭제되므로 `cascade` 속성을 추가로 설정하지 않아도 된다.**

## `@Entity` — `cascade` 설정 필수

> [!warning]
> 애그리거트에 속한 **`@Entity` 타입에 대한 매핑은 `cascade` 속성을 사용해서 저장과 삭제 시에 함께 처리되도록 설정**해야 한다.
> **`@OneToOne`, `@OneToMany`는 `cascade` 속성의 기본값이 없으므로** 직접 지정해야 한다.

```java
@OneToMany(cascade = {CascadeType.PERSIST, CascadeType.REMOVE},
           orphanRemoval = true)
@JoinColumn(name = "product_id")
@OrderColumn(name = "list_idx")
private List<Image> images = new ArrayList<>();
```

| 설정 | 효과 |
|------|------|
| `CascadeType.PERSIST` | 루트 **저장 시 함께 저장** |
| `CascadeType.REMOVE` | 루트 **삭제 시 함께 삭제** |
| `orphanRemoval = true` | **컬렉션에서 제거하면 DB에서도 삭제** |

## Exam/Test Patterns (시험 빈출 패턴)

| Scenario/Keyword | Answer |
|-------------------|--------|
| "저장/삭제 시 애그리거트 처리 단위" | **애그리거트 전체** |
| "`@Embeddable`에 `cascade`가 필요한가?" | **불필요** (자동으로 함께 처리) |
| "`@Entity` 매핑에 `cascade`가 필요한가?" | **필요** (`@OneToOne`/`@OneToMany`는 기본값 없음) |
| "지정해야 할 `CascadeType`" | **`PERSIST`, `REMOVE`** |
| "컬렉션에서 제거 시 DB 삭제" | **`orphanRemoval = true`** |
