# 외부 시스템 연동과 도메인 서비스 (★★)

#ddd #domain-service #external-integration #concept

## Overview Table (한눈에 비교)

| 항목 | 핵심 내용 |
|------|-----------|
| 대상 | **외부 시스템이나 타 도메인과의 연동 기능**도 도메인 서비스가 될 수 있다 |
| 핵심 기법 | **도메인 언어로 인터페이스를 정의**하고, 연동 구현은 인프라스트럭처에 둔다 |
| 인터페이스 위치 | **도메인 영역** |
| 구현 클래스 위치 | **인프라스트럭처 영역** |
| 효과 | 응용 서비스는 **"연동"이 아니라 "권한 검사"라는 도메인 개념으로** 코드를 읽게 된다 |

## 예 — 설문 조사 생성 권한 검사

> 설문 조사 시스템과 사용자 역할 관리 시스템이 분리되어 있다고 하자.
> 설문 조사 시스템은 설문 조사를 생성할 때 **사용자가 생성 권한을 가진 역할인지 확인하기 위해 역할 관리 시스템과 연동**해야 한다.

### 도메인 영역 — 인터페이스

```java
public interface SurveyPermissionChecker {
    boolean hasUserCreationPermission(String userId);
}
```

> [!important] 이름에 주목
> 인터페이스 이름이 `RoleSystemClient`나 `HttpApiCaller`가 아니라 **`SurveyPermissionChecker`** 다.
> 메서드도 `callRoleApi()`가 아니라 **`hasUserCreationPermission()`** 이다.
> → **연동이라는 구현 관심사가 아니라 "권한을 가졌는가"라는 도메인 개념을 표현**한다.

### 응용 서비스 — 도메인 개념으로 사용

```java
public class CreateSurveyService {
    private SurveyPermissionChecker permissionChecker;

    public Long createSurvey(CreateSurveyRequest req) {
        validate(req);
        // 도메인 서비스를 이용해서 외부 시스템 연동을 표현
        if (!permissionChecker.hasUserCreationPermission(req.getRequestorId())) {
            throw new NoPermissionException();
        }
        ...
    }
}
```

### 인프라스트럭처 영역 — 구현

> **`SurveyPermissionChecker` 인터페이스를 구현한 클래스는 인프라스트럭처 영역에 위치해 연동을 구현한다.**

```
   [ 도메인 영역 ]
   «interface» SurveyPermissionChecker
                    △
   ─ ─ ─ ─ ─ ─ ─ ─ ─╎─ ─ ─ ─ ─ ─ ─ ─ ─
   [ 인프라스트럭처 영역 ]
       HttpRoleSystemPermissionChecker
              (REST API 호출 등)
```

> [!tip] DIP의 적용
> 이것은 2장 [[DIP]]에서 배운 **"추상화한 인터페이스는 고수준 모듈 관점에서 도출하고 고수준 모듈에 위치시킨다"** 는 원칙의 적용이다.
> `RuleEngine`(저수준 관점) ❌ vs `RuleDiscounter`(고수준 관점) ⭕ 와 같은 구조다.

## Exam/Test Patterns (시험 빈출 패턴)

| Scenario/Keyword | Answer |
|-------------------|--------|
| "외부 시스템 연동도 도메인 서비스가 되나?" | **된다** |
| "인터페이스 이름을 지을 때 기준" | **도메인 개념**(`SurveyPermissionChecker`), 연동 기술 아님 |
| "인터페이스는 어느 영역?" | **도메인 영역** |
| "연동 구현 클래스는 어느 영역?" | **인프라스트럭처 영역** |
| "어떤 원칙의 적용인가" | **DIP** — 인터페이스는 고수준 모듈에 위치 |
