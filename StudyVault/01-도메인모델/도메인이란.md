# 도메인이란? (★★)

#ddd #domain-model #concept

## Overview Table (한눈에 비교)

| 항목 | 핵심 내용 |
|------|-----------|
| **도메인(domain)** | 소프트웨어로 **해결하고자 하는 문제 영역** |
| **하위 도메인(subdomain)** | 한 도메인을 기능 단위로 나눈 영역 (카탈로그·주문·결제·배송·혜택·회원 등) |
| 하위 도메인 간 관계 | 서로 연동해서 완전한 기능을 제공 |
| 구현 주체 | 도메인 기능을 **전부 직접 구현하지 않는다** — 외부 업체 시스템 연동이 흔함 |
| 하위 도메인 구성 | **고정된 정답이 없다.** 비즈니스 상황에 따라 달라진다 |

## 도메인 = 문제 영역

개발자 입장에서 온라인 서점은 구현해야 할 소프트웨어의 대상이다. 상품 조회, 구매, 결제, 배송 추적 등의 기능을 제공해야 하며, 이때 **온라인 서점이라는 문제 영역 자체가 도메인**이다.

> [!tip] 도메인은 "기술"이 아니라 "문제"다
> 도메인은 DB·프레임워크 같은 해결 수단이 아니라, 소프트웨어가 풀어야 할 **비즈니스 문제 영역**을 가리킨다.

## 하위 도메인으로의 분해

```
                    [ 온라인 서점 도메인 ]
                             │
   ┌───────┬───────┬─────────┼─────────┬───────┬───────┐
 카탈로그  주문    결제      배송     혜택   리뷰   회원
   │       │       │         │        │
 상품정보 주문서  결제수단  배송추적  쿠폰/
 가격/상세 취소   PG연동    송장     포인트
```

- 고객이 물건을 구매하면 **주문 → 결제 → 배송 → 혜택** 하위 도메인의 기능이 함께 동작한다.
- 각 하위 도메인은 독립적으로 존재하지 않고 **서로 연동**하여 완전한 기능을 이룬다.

## 직접 구현 vs 외부 연동

특정 도메인을 위한 소프트웨어라고 해서 그 도메인의 **모든 기능을 직접 구현하지는 않는다.**

| 하위 도메인 | 흔한 처리 방식 |
|-------------|----------------|
| 배송 | 자체 배송 시스템 구축 대신 **외부 물류/택배사 시스템 연동**, 배송 추적 정보만 일부 제공 |
| 결제 | 직접 구현 대신 **결제 대행업체(PG)** 이용 |

```
      [ 자체 시스템 ]                    [ 외부 시스템 ]
   ┌──────────────────┐             ┌──────────────────┐
   │ 주문 / 카탈로그   │  ──연동──▶  │ 외부 물류 (배송)  │
   │ 회원 / 혜택       │  ──연동──▶  │ 결제 대행사 (PG)  │
   └──────────────────┘             └──────────────────┘
        배송 도메인의 일부 기능만 자체 구현, 나머지는 외부 업체 시스템 사용
```

## 하위 도메인 구성은 상황에 따라 달라진다

> [!warning] "모든 쇼핑몰에 동일한 하위 도메인이 존재한다"는 착각
> 정해진 하위 도메인 집합은 존재하지 않는다.
> - 모든 온라인 쇼핑몰이 **고객 혜택**을 제공하는 것은 아니다.
> - 규모가 크지 않은 소규모 업체는 **엑셀 같은 도구로 정산을 수작업 처리**하기도 한다.

| 비즈니스 유형 | 필요한 하위 도메인 |
|---------------|--------------------|
| 기업 고객 대상 **대형 장비 판매** | 온라인 카탈로그 + 주문서 접수 정도. 온라인 결제·배송 추적 불필요 |
| 일반 고객 대상 **의류/액세서리 판매** | 카탈로그, 리뷰, 주문, 결제, 배송, 회원 기능 등 대부분 필요 |

## Exam/Test Patterns (시험 빈출 패턴)

| Scenario/Keyword | Answer |
|-------------------|--------|
| "소프트웨어로 해결하고자 하는 문제 영역" | **도메인(domain)** |
| "온라인 서점을 카탈로그/주문/결제/배송으로 나눔" | **하위 도메인(subdomain)으로 분해** |
| "배송 기능이 필요한데 직접 구현하지 않았다" | 정상. **외부 업체 시스템 연동**이 일반적 |
| "모든 쇼핑몰은 혜택 하위 도메인을 가진다?" | **거짓.** 하위 도메인 구성은 상황에 따라 다름 |
| "소규모 업체가 엑셀로 정산 처리" | 하위 도메인을 **소프트웨어로 구현하지 않을 수도 있음** |
