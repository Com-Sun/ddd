## 추천 학습 순서

```
   [ 1단계 — 개념 기초 ]
   1장 도메인 모델 → 2장 아키텍처 → 3장 애그리거트
                                        │
   [ 2단계 — 구현 ]                      ▼
   4장 리포지터리/JPA 매핑 → 5장 조회 기능
                                        │
   [ 3단계 — 설계 원칙 ]                 ▼
   6장 응용/표현 영역 → 7장 도메인 서비스
                                        │
   [ 4단계 — 심화 ]                      ▼
   8장 트랜잭션 관리 → 9장 바운디드 컨텍스트 → 10장 이벤트 → 11장 CQRS
```

> [!tip] 시간이 없다면
> **1 → 2 → 3 → 7 → 9 → 11장** 순서로 **개념만** 훑어도 DDD의 큰 그림을 잡을 수 있다.
> 4·5장은 **JPA 구현 레퍼런스**이므로 필요할 때 찾아보면 된다.
