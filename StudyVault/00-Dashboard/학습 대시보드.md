### 미해결 개념 (다음 드릴 대상)

- 01-도메인모델: DB 스키마 ≠ 도메인 모델 / private setter 예외 / **cardinality(1:N)는 기준이 아니다 ⚠️ 2회 반복** / **밸류 "추출" vs 엔티티 "추적" 방향 차이 (판별 질문 3개)**
- 03-애그리거트: 판정 결과의 코드 반영 (컬렉션 vs ID 참조) / 변경 주체 = 역할이지 코드 진입점이 아니다
- 04-리포지터리와모델구현: 밸류 컬렉션 매핑 / **객체↔관계형 대응 (밸류 저장 4패턴)** / `@Embeddable` vs `@Entity` clear() 성능
  - ⬜ **미테스트 5건** (Q10·Q11·Q12에서 설명만 함): `@AttributeOverride`가 필요한 이유 · 컬럼 개수 = 필드 개수 · 4패턴을 무엇이 결정하나 · **행을 특정하는 것의 출처(부모 파생=밸류)** · Fowler PoEAA 패턴명 대응
- 05-스프링데이터JPA조회: Pageable 변환 / COUNT 쿼리 규칙 / Specification
- 10-이벤트: 포워더와 offset / 자동 증가 칼럼 누락
