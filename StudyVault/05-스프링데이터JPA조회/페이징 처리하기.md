# 페이징 처리하기 (★★★)

#ddd #query #paging #spring #concept

## Overview Table (한눈에 비교)

| 타입 | 역할 |
|------|------|
| **`Pageable`** | 페이징 정보를 전달하는 **인터페이스** (마지막 파라미터) |
| **`PageRequest`** | 실제 `Pageable` 객체를 생성하는 **클래스** |
| **`Page<T>`** | 목록 + **전체 개수·페이지 수 등 페이징 메타 정보** |
| **`List<T>`** | 목록만 (COUNT 쿼리 회피 가능) |

## ★ COUNT 쿼리 실행 규칙 (가장 중요)

| 메서드 형태 | 리턴 타입 | COUNT 쿼리 |
|-------------|-----------|------------|
| `findByXxx(..., Pageable)` | **`Page`** | ⭕ **실행** |
| `findByXxx(..., Pageable)` | **`List`** | ❌ **실행 안 함** |
| **`findAll(Specification, Pageable)`** | **`List`여도** | ⭕ **실행** |

> [!danger] 핵심 함정
> **프로퍼티를 비교하는 `findBy` 형식의 메서드**는 `Pageable`을 사용하더라도 **리턴 타입이 `List`면 COUNT 쿼리를 실행하지 않는다.**
>
> **반면에 스펙을 사용하는 `findAll` 메서드에 `Pageable`을 사용하면 리턴 타입이 `Page`가 아니어도 COUNT 쿼리를 실행한다.**

```java
Page<MemberData> findByNameLike(String name, Pageable pageable);   // COUNT ⭕
List<MemberData> findByNameLike(String name, Pageable pageable);   // COUNT ❌

List<MemberData> findAll(Specification<MemberData> spec, Pageable pageable);  // COUNT ⭕ (!)
```

> [!tip] 최적화
> 페이징 처리와 관련된 **정보가 필요 없다면 `Page` 리턴 타입이 아닌 `List`를 사용**해서 불필요한 COUNT 쿼리를 실행하지 않도록 한다.
>
> **스펙을 사용하면서 COUNT 쿼리를 실행하고 싶지 않다면**, 스프링 데이터 JPA가 제공하는 **커스텀 리포지터리 기능**을 이용해서 직접 구현해야 한다.

## 기본 사용

```java
import org.springframework.data.domain.Pageable;

public interface MemberDataDao extends Repository<MemberData, String> {
    List<MemberData> findByNameLike(String name, Pageable pageable);
}
```

```java
import org.springframework.data.domain.PageRequest;

PageRequest pageReq = PageRequest.of(1, 10);
List<MemberData> user = memberDataDao.findByNameLike("사용자%", pageReq);
```

> [!important] 페이지 번호는 0부터 시작한다
> `PageRequest.of()`의 **첫 번째 인자는 페이지 번호**, **두 번째 인자는 한 페이지의 개수**를 의미한다.
> **페이지 번호는 0번부터 시작**하므로 위 코드는 한 페이지에 10개씩 표시할 때 **두 번째 페이지**를 조회한다.
> 즉 **11번째부터 20번째까지** 데이터를 조회한다.

```
   PageRequest.of(0, 10)  →  1~10번째    (1페이지)
   PageRequest.of(1, 10)  →  11~20번째   (2페이지)  ★
   PageRequest.of(2, 10)  →  21~30번째   (3페이지)
```

## `PageRequest` + `Sort`

```java
Sort sort = Sort.by("name").descending();
PageRequest pageReq = PageRequest.of(1, 2, sort);
List<MemberData> user = memberDataDao.findByNameLike("사용자%", pageReq);
```

## `Page` 타입 — 페이징 메타 정보

```java
import org.springframework.data.domain.Page;
import org.springframework.data.domain.Pageable;

public interface MemberDataDao extends Repository<MemberData, String> {
    Page<MemberData> findByBlocked(boolean blocked, Pageable pageable);
}
```

> `Pageable`을 사용하는 메서드의 **리턴 타입이 `Page`일 경우** 스프링 데이터 JPA는
> **목록 조회 쿼리와 함께 COUNT 쿼리도 실행**해서 조건에 해당하는 데이터 개수를 구한다.

```java
Pageable pageReq = PageRequest.of(2, 3);
Page<MemberData> page = memberDataDao.findByBlocked(false, pageReq);

List<MemberData> content   = page.getContent();          // 조회 결과 목록
long totalElements         = page.getTotalElements();    // 조건에 해당하는 전체 개수
int totalPages             = page.getTotalPages();       // 전체 페이지 번호
int number                 = page.getNumber();           // 현재 페이지 번호
int numberOfElements       = page.getNumberOfElements(); // 조회 결과 개수
int size                   = page.getSize();             // 페이지 크기
```

### 스펙과 함께

```java
public interface MemberDataDao extends Repository<MemberData, String> {
    Page<MemberData> findAll(Specification<MemberData> spec, Pageable pageable);

```

## `First` / `Top` — 처음 N개만

> 처음부터 **N개의 데이터가 필요하다면 `Pageable`을 사용하지 않고 `findFirstN` 형식**의 메서드를 사용할 수도 있다.

```java
List<MemberData> findFirst3ByNameLikeOrderByName(String name);
```

> `name` 프로퍼티 기준으로 `like`를 검색한 결과를 `name` 프로퍼티 기준 **오름차순으로 정렬해서 처음 3개**를 조회한다.

| 키워드 | 의미 |
|--------|------|
| `First3` / `Top3` | 처음 **3개** |
| **`First` / `Top`** (숫자 없음) | 처음 **1개** |

```java
MemberData findFirstByBlocked(boolean blocked);
```

## Exam/Test Patterns (시험 빈출 패턴)

| Scenario/Keyword | Answer |
|-------------------|--------|
| "페이징 파라미터 타입 / 생성 클래스" | **`Pageable`** / **`PageRequest`** |
| "`PageRequest.of(1, 10)`이 조회하는 범위" | **11~20번째** (페이지 번호는 **0부터**) |
| "`Page` 리턴 시 실행되는 추가 쿼리" | **COUNT 쿼리** |
| "`findByXxx(..., Pageable)` + `List` 리턴" | COUNT 쿼리 **실행 안 함** |
| "`findAll(Spec, Pageable)` + `List` 리턴" | COUNT 쿼리 **실행함** ⚠️ |
| "COUNT를 피하려면" | `List` 리턴 / 스펙이면 **커스텀 리포지터리** |
| "전체 개수 / 전체 페이지 수" | `getTotalElements()` / `getTotalPages()` |
| "처음 3개만 조회" | **`findFirst3By...`** 또는 `findTop3By...` |
| "`First`에 숫자가 없으면" | **1개** |
