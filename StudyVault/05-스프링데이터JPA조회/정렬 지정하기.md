# 정렬 지정하기 (★★)

#ddd #query #sorting #spring #concept

## Overview Table (두 가지 방법)

| 방법 | 형식 | 장점 | 단점 |
|------|------|------|------|
| **① 메서드 이름에 `OrderBy`** | `findByOrdererIdOrderByNumberDesc` | **간단** | 프로퍼티 2개 이상이면 **이름이 길어짐**, **런타임에 순서 변경 불가** |
| **② `Sort` 인자 전달** | `findByOrdererId(String, Sort)` | **동적으로 정렬 순서 변경 가능** | 코드가 한 줄 더 |

## ① 메서드 이름에 `OrderBy`

```java
public interface OrderSummaryDao extends Repository<OrderSummary, String> {
    List<OrderSummary> findByOrdererIdOrderByNumberDesc(String ordererId);
}
```

이 메서드는 다음 조회 쿼리를 생성한다.

- `ordererId` 프로퍼티 값을 기준으로 **검색 조건 지정**
- `number` 프로퍼티 값 **역순으로 정렬**

### 두 개 이상의 프로퍼티

```java
findByOrdererIdOrderByOrderDateDescNumberAsc(String ordererId)
```

```
   OrderBy  OrderDate Desc  Number Asc
            └── ① 내림차순  └── ② 오름차순
```

> 먼저 `orderDate` 프로퍼티를 기준으로 **내림차순**으로 정렬하고, 다음에 `number` 프로퍼티를 기준으로 **오름차순**으로 정렬하는 쿼리를 생성한다.

> [!warning] 한계
> - 정렬 기준 프로퍼티가 **두 개 이상이면 메서드 이름이 길어지는 단점**이 있다.
> - **메서드 이름으로 정렬 순서가 정해지기 때문에 상황에 따라 정렬 순서를 변경할 수 없다.**

## ② `Sort` 타입 사용

```java
import org.springframework.data.domain.Sort;

public interface OrderSummaryDao extends Repository<OrderSummary, String> {
    List<OrderSummary> findByOrdererId(String ordererId, Sort sort);
    List<OrderSummary> findAll(Specification<OrderSummary> spec, Sort sort);
}
```

> **`find` 메서드에 마지막 파라미터로 `Sort`를 추가**했다. 스프링 데이터 JPA는 전달받은 `Sort`를 사용해서 **알맞게 정렬 쿼리를 생성**한다.

### 사용

```java
Sort sort = Sort.by("number").ascending();
List<OrderSummary> results = orderSummaryDao.findByOrdererId("user1", sort);
```

### 두 개 이상의 정렬 순서 — `and()`

```java
Sort sort1 = Sort.by("number").ascending();
Sort sort2 = Sort.by("orderDate").descending();
Sort sort = sort1.and(sort2);
```

**짧게 표현하기**

```java
Sort sort = Sort.by("number").ascending()
                .and(Sort.by("orderDate").descending());
```

## Exam/Test Patterns (시험 빈출 패턴)

| Scenario/Keyword | Answer |
|-------------------|--------|
| "정렬 지정 두 방법" | **메서드 이름 `OrderBy`** / **`Sort` 인자** |
| "`findByOrdererIdOrderByNumberDesc`" | ordererId로 검색 + **number 역순 정렬** |
| "메서드 이름 방식의 단점 2가지" | **이름이 길어짐** + **런타임 변경 불가** |
| "`Sort` 파라미터 위치" | `find` 메서드의 **마지막 파라미터** |
| "오름차순/내림차순 메서드" | **`.ascending()` / `.descending()`** |
| "두 정렬 결합" | **`Sort.and()`** |
