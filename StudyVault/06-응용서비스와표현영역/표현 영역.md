# 표현 영역 (★★)

#ddd #presentation-layer #concept

## Overview Table (세 가지 책임)

| # | 책임 | 설명 |
|---|------|------|
| **①** | **알맞은 흐름 제공** | 사용자가 시스템을 사용할 수 있도록 화면·링크·폼 등 흐름을 제공 |
| **②** | **응용 서비스에 기능 실행 요청** | 요청 데이터 ↔ 응답 형식 **변환** |
| **③** | **세션(연결 상태) 관리** | 쿠키나 서버 세션으로 사용자 연결 상태 관리 |

## ① 알맞은 흐름 제공

> 표현 영역은 **사용자가 요청한 내용을 응답으로 제공**한다.
> 응답에는 **다음 화면으로 이동할 수 있는 링크나 데이터를 입력하는 데 필요한 폼** 등이 포함된다.

```
 사용자         표현 영역        응용 서비스
   │  게시글 쓰기 요청 │              │
   │──────────────▶│              │
   │              │─1.1 필요 데이터 조회─▶│
   │              │◀─1.2 데이터 리턴────│
   │◀─1.3 폼 화면 응답─│              │
   │              │              │
   │  폼 전송        │              │
   │──────────────▶│─2.1 게시글 쓰기 실행─▶│
```

## ② 응용 서비스에 기능 실행 요청 + 변환

> [!important]
> 표현 영역의 핵심 역할은 **사용자의 요청에 맞게 응용 서비스에 기능 실행을 요청**하는 것이다.
> 이 과정에서 표현 영역은
> - **사용자의 요청 데이터를 응용 서비스가 요구하는 형식으로** 변환하고
> - **응용 서비스의 결과를 사용자에게 응답할 수 있는 형식으로** 변환한다.

### 직접 변환

```java
@PostMapping
public String changePassword(HttpServletRequest request, Errors errors) {
    // 표현 영역은 사용자 요청을 응용 서비스가 요구하는 형식으로 변환한다.
    String curPw = request.getParameter("curPw");
    String newPw = request.getParameter("newPw");
    String memberId = SecurityContext.getAuthentication().getId();
    ChangePasswordRequest chPwdReq =
            new ChangePasswordRequest(memberId, curPw, newPw);

    try {
        // 응용 서비스를 실행
        changePasswordService.changePassword(chPwdReq);
        return successView;
    } catch (BadPasswordException | NoMemberException ex) {
        // 응용 서비스의 처리 결과를 알맞은 응답으로 변환
        errors.reject("idPasswordNotMatch");
        return formView;
    }
}
```

### 프레임워크 기능 활용

```java
// 프레임워크가 제공하는 기능을 사용해서
// HTTP 요청을 응용 서비스의 입력으로 쉽게 변경 처리
@PostMapping
public String changePassword(ChangePasswordRequest chPwdReq, Errors errors) {
    String memberId = SecurityContext.getAuthentication().getId();
    chPwdReq.setMemberId(memberId);
    try {
        changePasswordService.changePassword(chPwdReq);
        return successView;
    } catch (BadPasswordException | NoMemberException ex) {
        // 응용 서비스의 처리 결과를 알맞은 응답으로 변환
        errors.reject("idPasswordNotMatch");
        return formView;
    }
}
```

> [!tip]
> **응용 서비스의 실행 결과를 사용자에게 알맞은 형식으로 제공하는 것도 표현 영역의 역할**이다.
> 위 코드는 응용 서비스에서 익셉션이 발생하면 **에러 코드를 설정**하고, 뷰는 **에러 코드에 알맞은 처리**(해당 메시지 출력 등)를 한다.

## ③ 세션 관리

> [!important]
> 표현 영역의 다른 주된 역할은 **사용자의 연결 상태인 세션을 관리**하는 것이다.
> 웹은 **쿠키나 서버 세션**을 이용해서 사용자의 연결 상태를 관리한다.
> **세션 관리는 권한 검사와도 연결**된다. → [[권한 검사]]

> [!warning] 응용 서비스가 침범하면 안 된다
> `HttpSession`이나 쿠키는 **표현 영역의 상태**다.
> 응용 서비스가 이를 조작하면 표현 영역의 응집도가 깨진다.
> → [[표현 영역에 의존하지 않기와 트랜잭션 처리]]
